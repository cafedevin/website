CAFÉ DEVIN – GITHUB YÜKLEME REHBERİ

1. Önce mevcut cafedevin/website deponun yedeğini al.
2. ZIP dosyasını aç. İçindeki DOSYALARI (ZIP değil) GitHub > cafedevin/website > Add file > Upload files bölümüne yükle.
3. index.html, impressum.html, logo.png, CNAME ve diğer dosyalar depo kökünde olmalı. images klasörü de aynı düzeyde olmalı.
4. Mevcut logo.png dosyasını değiştirme; bu pakette logo bulunmaz, depodaki gerçek logo kullanılır.
5. CNAME dosyası cafedevin.de olarak ayarlı. Mevcut alan adı ayarın farklıysa mevcut CNAME içeriğini koru.
6. Commit changes ile kaydet. GitHub Pages ayarlarını kontrol et.
7. Yayından önce: fiyatı bilinmeyen ürünlerin fiyatını tamamla; çalışma saatlerini ve ürün fotoğraflarını doğrula; Impressum ve Datenschutz metinlerini hukuki kontrolden geçir.
8. Reservierung: form yerine telefon ve e-posta bağlantısı var; otomatik rezervasyon sistemi değildir.
9. Site hiçbir çerez/analitik scripti veya harici font yüklemiyor; ileride eklenirse Datenschutz güncellenmelidir.
